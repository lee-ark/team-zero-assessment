# Raisely Assessment

A small Express API for managing fundraising profiles and donations.

## Requirements

- Node.js >= 18

## Setup

```bash
npm install
```

## Running

```bash
npm start
```

Server runs at `http://localhost:8080`.

## Tests

```bash
npm test
```

## Coding Agents

Use of AI coding agents is allowed and encouraged for this assessment.

If you don't have one, [OpenCode](https://opencode.ai) is a free, open-source agent that runs in your terminal. It includes free models via OpenCode Zen — no API key required.

**Install:**

```bash
curl -fsSL https://opencode.ai/install | bash
```

Then run `opencode` in your project directory to get started.
